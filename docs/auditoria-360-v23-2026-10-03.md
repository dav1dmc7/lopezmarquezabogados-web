# Auditoría 360º — v23

## Estado

El smoke test de producción ya demuestra HTTP 200 para las rutas principales y 301/200 para legacy. La v23 añade dos capas que faltaban:

### SEO/renderizado live
`npm run audit:seo-live` comprueba sobre el HTML realmente servido:
- status final y redirects;
- exactamente un `<title>`;
- exactamente un H1 renderizado;
- ausencia de `noindex`;
- canonical del host correcto;
- `og:title` y `og:description`;
- sitemap XML válido;
- línea Sitemap en robots.txt.

### Performance local
`npm run audit:performance-local` mide la build real:
- tamaño total de `dist`;
- bytes JS/CSS/imágenes;
- 15 archivos más pesados;
- viewport y stylesheet básicos en HTML;
- avisos para bundles grandes e imágenes >1.5 MB.

No se añade ninguna herramienta de pago y no se toca DNS.

## Analítica
La capa de eventos de comportamiento ya está instrumentada en el proyecto. La activación del proveedor gratuito se realiza en Cloudflare; la analítica debe permanecer detrás del mecanismo de consentimiento configurado.
