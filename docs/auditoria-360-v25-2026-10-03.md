# Auditoría 360 v25 — 2026-10-03

## Objetivo
Resolver de forma segura el problema real detectado en `logo.svg`: dos `data:` URI embebidos mantienen el SVG alrededor de 2.92 MB, pese a la optimización básica con SVGO.

## Cambios
- Mantener `astro check` sin hints.
- Sustituir el uso incorrecto de `bash -n` para JavaScript por `node --check` en el procedimiento de QA.
- Añadir `scripts/audit-asset-embeds.mjs` para medir MIME, encoding y tamaño decodificado de cada `data:` URI.
- Externalizar automáticamente los payloads de imagen embebidos superiores a 100 KB a archivos bajo `public/brand/`, conservando los bytes originales para evitar pérdidas de calidad.
- Reforzar `audit-assets-local.mjs` para mostrar los activos más pesados y si aparecen referenciados desde HTML/CSS.
- Sin cambios de DNS, Cloudflare, D1, correo o dominio.
