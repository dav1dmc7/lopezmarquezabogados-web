# Auditoría 360 v24 — 2026-10-03

## Objetivo
Cerrar el único hint de `astro check` y reforzar la auditoría de rendimiento local detectando SVG sobredimensionados.

## Hallazgo que motiva v24
`dist/brand/logo.svg` tenía aproximadamente 2.92 MB. El presupuesto anterior solo avisaba de raster images, por lo que ese SVG no generaba warning.

## Cambios
- Eliminado el import `existsSync` no utilizado.
- Añadido presupuesto explícito para SVG > 750 KB en `audit-performance-local`.
- Añadido `audit:assets-local` para revisar activos grandes y detectar data URIs en `brand/logo.svg`.
- Intento de optimización de `public/brand/logo.svg` mediante SVGO. Si SVGO falla o devuelve un resultado inválido, se conserva el original.
- No se modifican DNS, Cloudflare, D1, correo ni registros de dominio.

## Validación esperada
Ejecutar:

```bash
npm run verify
npm run audit:seo-live
npm run audit:performance-local
npm run audit:assets-local
git diff --check
git status
```

El objetivo es terminar con `astro check` sin hints y revisar cuánto ha bajado el peso real del logo.
