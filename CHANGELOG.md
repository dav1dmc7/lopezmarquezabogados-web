# Changelog

## 1.1.0 — Fundamentos de producción

- Nueva arquitectura Astro + Cloudflare Workers Static Assets.
- Arquitectura SEO por intención para Laboral, Extranjería y Empresas.
- Rutas de soporte para Civil, Penal y Administrativo.
- Recursos jurídicos iniciales con fuentes oficiales.
- Redirects 301 desde las rutas HTML históricas.
- Cabeceras de seguridad y `robots.txt`.
- Formulario de consulta sin almacenamiento propio: deriva a WhatsApp.
- Sitemap y datos estructurados `LegalService`/`LocalBusiness`.
- Contenido de Extranjería actualizado para el régimen vigente en 2026.
- Home ampliada con rutas de entrada por situación y sección de recursos.
- Open Graph actualizado a imagen PNG.
- Política de trailing slash fijada en Cloudflare Workers.
- Workflow de GitHub Actions para check, audit y build.
- Auditoría con controles de H1, claves expuestas y enlaces externos.
